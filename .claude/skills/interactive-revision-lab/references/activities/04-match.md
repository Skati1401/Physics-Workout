# Activity 4: Match (interactive-revision-lab)

Shared rules (headings, no capitals, checklist, verification) are in SKILL.md; the engine helpers, layout and equations are in the `workout-page-shell` skill.

`createMatchGame(cfg)` factory: two independently-shuffled columns ("Feature" / "Why it works" or similar), tentative `pairs{}` state, drag-to-pair or tap-to-select-then-tap-to-pair. An SVG `<line>` overlay (absolutely positioned over a `position:relative` grid) draws a line between each paired card's edge midpoints, recomputed via `requestAnimationFrame` after every render and on window resize (also expose a `reflow()` and call it whenever the tab containing this game becomes visible again, since a hidden panel's cards have zero layout size and the line coordinates would be wrong). Two things matter for legibility: equalize both columns' card heights after each render (a flat px `min-height`, not em — see "Uniform card/item height" in the `workout-page-shell` skill) so pairs don't look mismatched, and give the two-column grid a generous `column-gap` (~40px) so the connecting lines are easy to trace. Write the left-column text at similar length to the right-column text (roughly the same number of lines) rather than short label vs. long explanation.

# Activity 5: Reveal Example (interactive-revision-lab)

Shared rules (headings, no capitals, checklist, verification) are in SKILL.md; the engine helpers, layout and equations are in the `workout-page-shell` skill.

For worked examples / model answers, not a graded activity — use native `<details><summary>Check your answer</summary>...</details>`, no JS needed. Style the `<summary>` with a custom `+`/`−` marker (hide the default triangle via `summary::-webkit-details-marker{display:none}` and a `::before` content swap on `[open]`). Pair each example with a small labelled inline-SVG diagram above the question (simple line-art, same icon style as the rest of the page). Write the revealed model answer as **bullet points**, not prose paragraphs, if that's the school's house style for how students should write answers — each bullet one step of the reasoning chain. Good pattern: one single-mechanism example + one multi-mechanism example, so students see both a short and a longer expected answer. **If the example is a numeric calculation, prefer pattern 10 (Type-the-Number) instead of pure reveal** — letting the student type their own answer and get it graded is strictly more active than reading a revealed answer, and the worked-solution `<details>` can still sit underneath as "Show full working" for after they've had a go.

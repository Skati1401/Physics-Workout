# Activity 8: Flip-Card Memory Match (interactive-revision-lab)

Shared rules (headings, no capitals, checklist, verification) are in SKILL.md; the engine helpers, layout and equations are in the `workout-page-shell` skill.

`createMemoryGame(cfg)` factory: `cfg = {prefix, pairs:[{id, a, b}]}` where `a`/`b` are e.g. a term and its definition. Generate `2×pairs.length` cards (each showing a card-back by default), shuffle positions. Click/tap flips a card face-up (CSS 3D flip via `transform: rotateY(180deg)` on a `.card-inner` with `backface-visibility:hidden` front/back faces — cheap and reliable, no JS animation library needed). Track `firstPick`/`secondPick`: on a second flip, compare `pairId`; match → both cards lock face-up (`.is-matched`, subtle scale/glow, stop being clickable); no match → brief pause (~800ms) showing both, then flip back down. Track flip count as a simple built-in "score" (fewer flips = better) shown in a small counter, and reset it on "Shuffle Again". Keep the deck to 8-10 pairs (16-20 cards) — legible in a grid, doesn't drag on. Forces example pairs: "Friction" ↔ "Opposes motion between two surfaces in contact", "Normal force" ↔ "Acts perpendicular to a surface, pushing objects apart", "Tension" ↔ "Pulls along a rope or string", "Air resistance" ↔ "Opposes motion through a fluid, increases with speed".
